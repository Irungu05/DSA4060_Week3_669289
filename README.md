## 1. Project Overview & Objective
This project implements a **Content-Based Filtering Recommender System** using structured binary item features and user preference modeling in Python and pandas[cite: 1]. The system generates personalized Top-N movie recommendations by converting user rating history into a normalized preference profile and scoring candidate items.
